# Quick Installation Guide

## Step 1: Download Extension
1. Download the `BetterCanvas2` folder to your computer
2. Keep all files together in the same folder

## Step 2: Open Chrome Extensions
1. Open Google Chrome
2. Go to `chrome://extensions/`
3. Turn ON "Developer mode" (top right toggle)

## Step 3: Load Extension
1. Click "Load unpacked" button
2. Select the `BetterCanvas2` folder
3. Click "Select Folder"

## Step 4: Pin Extension
1. Click the puzzle piece icon in Chrome toolbar
2. Find "Better Canvas" in the list
3. Click the pin icon next to it

## Step 5: Use on Canvas
1. Go to your Canvas page (e.g., canvas.gmu.edu)
2. Click the Better Canvas icon in toolbar
3. Toggle features on/off as needed

## Troubleshooting
- **Not working?** Make sure you're on a Canvas page
- **Can't see icon?** Check if extension is pinned
- **Settings not saving?** Try refreshing the page

That's it! Enjoy your enhanced Canvas experience! 🎓
