# Contributing

Bugs and pull requests are welcome. Load the extension unpacked from this folder, then reload it on `chrome://extensions/` after each change.

## Check a change

1. Open a Canvas dashboard and a file viewer (a PDF or PowerPoint in Canvas).
2. Toggle Dark Mode, Hide Bloat, and Fullscreen Mode.
3. Reload the page and confirm the toggles still match `chrome.storage.sync`.

Say which Canvas host you used. Some Hide Bloat selectors were written against one school's dashboard cards.

## Pull requests

1. Describe the page the selector is meant to match.
2. Do not add host permissions broader than the current manifest unless the README explains why.
3. This project is [MIT](LICENSE). Your contribution is licensed the same way.
